# media/cover/ — `<creator>/<id>.png`, and `<creator>/_author.png`

Artwork, rendered by a local ComfyUI through `inductor artwork`. Off by default
(`enrich.covers` in `inductor.yaml`); a library with no covers is a perfectly
good library.

Hand-made or downloaded art belongs here too — set `cover:` on the item and
leave `cover` out of `provenance.generated`, so the site does not label somebody
else's work as machine-made.
